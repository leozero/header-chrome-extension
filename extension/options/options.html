Header Injector

Each rule matches the hostname of every request (pages, XHR/fetch, images, websockets…) against a regex, and adds, overrides or removes headers. Use ^ and $ to anchor: ^api\.example\.com$, (^|\.)example\.com$, ^localhost$.

Basic authentication

Fills the header with Basic base64(username:password). Base64 is an encoding, not encryption: the password is stored as readable as the header value.
